# Building MLflow Evaluation Datasets

An evaluation dataset is a curated set of example inputs (with or without ground-truth answers) used to systematically test and improve GenAI applications. This guide explains how to create and manage evaluation datasets using MLflow and Databricks.

---

## Requirements

To create an MLflow evaluation dataset:

- You must have `CREATE TABLE` permissions on a Unity Catalog schema.
- The dataset is attached to an MLflow experiment. If you don't have an experiment, see [Unit Evals](../foundations/unit-evals.md) for setup instructions.

---

## Data Sources for Evaluation Datasets

You can create datasets from:

1. **Existing traces** from production (most effective for real-world scenarios)
2. **Predefined datasets** or manually entered examples (useful for targeted testing)
3. **Synthetic data** generated by Databricks from your documents

---

## Create a Dataset Using the UI

Follow these steps to create a dataset from traces:

1. Navigate to **Experiments** in the sidebar.
2. Open your experiment and click **Traces** in the left sidebar.
3. Select traces using checkboxes.
4. Click **Actions** > **Add to evaluation dataset**.
5. Create a new dataset or add to an existing one in Unity Catalog.

> **Tip:** Use [Error Analysis](../error-analysis/overview.md) to identify high-impact traces for inclusion.

---

## Create a Dataset Using the SDK

### Step 1: Create the Dataset

```python
import mlflow
import mlflow.genai.datasets
from databricks.connect import DatabricksSession

spark = DatabricksSession.builder.remote(serverless=True).getOrCreate()

uc_schema = "workspace.default"
evaluation_dataset_table_name = "email_generation_eval"

eval_dataset = mlflow.genai.datasets.create_dataset(
    name=f"{uc_schema}.{evaluation_dataset_table_name}",
)
print(f"Created evaluation dataset: {uc_schema}.{evaluation_dataset_table_name}")
```

### Step 2: Add Records to the Dataset

#### From Existing Traces

```python
# Search for traces with specific attributes
traces = mlflow.search_traces(
    filter_string="attributes.status = 'OK'",
    max_results=10
)

# Add to dataset
eval_dataset = eval_dataset.merge_records(traces)
print(f"Added {len(traces)} records to evaluation dataset")
```

#### Selecting Traces for Evaluation

Use quantitative analysis to identify critical traces:

```python
# Find traces with quality issues
traces_df = mlflow.search_traces(
    filter_string="tag.quality_score < 0.7",
    max_results=100
)

# Analyze patterns (e.g., correlation with token usage)
correlation = traces_df["span.attributes.usage.total_tokens"].corr(traces_df["tag.quality_score"])
print(f"Correlation between token usage and quality: {correlation}")
```

## Dataset Management and Use Cases

Evaluation datasets enable:

- **Regression prevention** by creating "golden sets" of critical examples
- **Version comparison** across prompts, models, or app logic
- **Feature-specific testing** for safety, domain knowledge, or edge cases
- **LLMOps validation** across environments

> **Best Practice:** Store datasets in Unity Catalog for versioning, lineage, and governance.
