## GitHub Pages Site for AI Evaluators — Implementation Plan

### Context
- **Source content**: 30+ wiki articles organized in 11 topic folders, 4 checklists, 4+ diagram pages with pre-rendered PNG files, and a comprehensive References page.
- **Current hosting**: Azure DevOps (will remain; GitHub Pages is a separate public-facing site).
- **Existing tools**: `wikilinks_to_md.py` already converts Obsidian `[[links]]` to relative markdown links. Mermaid diagrams are pre-rendered as PNGs.
- **Engine**: MkDocs Material (Python-based, supports Mermaid natively, built-in search, dark mode, professional aesthetic).

---

### Implementation Steps

#### Step 1 — Scaffold the MkDocs project
Create a `docs/` folder at the repo root with:
- `mkdocs.yml` — site config (theme, nav, plugins, extensions)
- `docs/` — content directory (will mirror the wiki structure)

#### Step 2 — Configure `mkdocs.yml`
- **Theme**: Material with a custom color palette (dark/light toggle), professional typography
- **Plugins**: search, mermaid2 (for live rendering), table of contents, social cards
- **Nav structure**: Maps the 11 topic folders + Checklists + Diagrams + References into a clear navigation hierarchy
- **Extensions**: admonitions, footnotes, tables, task lists, code highlighting

#### Step 3 — Create the landing page (`docs/index.md`)
A professional homepage with:
- Hero section explaining the purpose
- Visual overview diagram (the lifecycle diagram from Home.md)
- Quick navigation cards to each major section
- "Who this is for" audience description

#### Step 4 — Port wiki content into `docs/`
- Copy wiki articles into `docs/` preserving folder structure
- Convert remaining `[[wiki-links]]` to standard markdown links using relative paths compatible with MkDocs
- Fix image paths to point to copied diagram PNGs
- Strip/convert frontmatter where needed (MkDocs uses `title` from H1 or meta)

#### Step 5 — Copy diagrams
- Copy all `wiki/Diagrams/auto/*.png` files to `docs/assets/diagrams/`
- Update image references in all articles
- Add live Mermaid rendering for key diagrams (MkDocs Material renders Mermaid natively in fenced blocks)

#### Step 6 — Create a References page (`docs/references.md`)
- Professional bibliography with all 11+ sources
- Categorized: Academic papers, Blog posts, Videos, Tooling docs
- Proper citation format with links

#### Step 7 — Add professional extras
- Custom CSS for callout boxes, quote styling, and diagram captions
- A `docs/assets/` folder for logo/favicon
- Social card metadata (Open Graph tags)
- Footer with attribution

#### Step 8 — GitHub Actions workflow
- `.github/workflows/deploy.yml` — builds and deploys to `gh-pages` branch on push to `main`
- Uses `mkdocs gh-deploy` action

#### Step 9 — Create a new GitHub repo and push
- Initialize a new GitHub repo (user will need to create it or we use `gh repo create`)
- Push the MkDocs project
- Enable GitHub Pages on the `gh-pages` branch
